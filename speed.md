## Initial analysis
React CRA client-side rendering: src/index.js uses createRoot. Customer pages use useResource without completed-response caching. Admin cache is in src/utils/resourceCache.js; live events in src/hooks/usePortalUpdates.js; backend MongoDB change streams are in backend/helpers/leadUpdates.js and resourceDomains.js. Some backend outputs aggregate orders, invoices, transactions and catalog products, and some values change with time. The feed requires MongoDB change streams and can be unavailable. Wallet balance is separately fetched in AppContent and falls back to localStorage; missing/expired cache returns 0. Tickets use query pagination. Customer documents combine user and lead data. Resource hooks track live updates but cache only selected admin resources. Existing frontend working tree already contains deleted README/docs and untracked Responsive.md and .responsive-verification-build; leave untouched.
